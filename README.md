# StockTrackAI

AI-powered dashboard that helps small traders track sales, stock, and debts — just by describing their day in plain language.

Built for the AI Factory Hackathon (native.builder), hosted by NativelyAI and lablab.ai.

## The Problem

Most small traders track their day on paper or in WhatsApp messages: what sold, what's owed, what's running low. Nothing is connected, so mistakes and missed debts pile up quietly.

## The Idea

A trader talks to StockTrackAI the way they'd talk to a friend — "sold 20 bags rice, gave supplier 5000, still owe him 3000" — and it turns that into real numbers: stock levels, who owes what, and alerts before something runs out or a debt goes unpaid too long.

## This Repo

Frontend for StockTrackAI — the dashboard traders use to see stock levels, debts, and alerts generated from their daily updates.

Built with native.builder.
